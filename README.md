# Exploratory 16S microbiome analysis in R

A Snakemake-managed workflow for reproducible downstream analysis of the `GlobalPatterns` 16S rRNA microbiome dataset included with the `phyloseq` R package.

The workflow validates a processed `phyloseq` dataset, generates alpha-diversity and Bray–Curtis PCoA results, and renders an HTML analysis report.

**Rendered report:** <https://UmutVrl.github.io/microbiome-rmarkdown-analysis/results/microbiome_16s_analysis.html>

## Research question

How do microbial alpha diversity, beta diversity, and taxonomic composition vary across sample types in the GlobalPatterns dataset?

## Analysis steps

1. Load and inspect the processed `GlobalPatterns` dataset.
2. Assess sequencing depth and rarefaction curves.
3. Remove features with zero total counts.
4. Calculate alpha diversity from rarefied counts at the minimum post-filtering depth.
5. Calculate Bray–Curtis dissimilarity from relative-abundance profiles.
6. Visualize between-sample relationships with PCoA.
7. Test the relationship between sample type and community composition with PERMANOVA and assess multivariate dispersion.
8. Visualize phylum-level taxonomic composition.

## Main findings

- Soil samples showed the highest observed richness and Shannon diversity.
- Freshwater creek samples had high richness but lower Shannon diversity and were dominated by Cyanobacteria.
- Sample type was strongly associated with Bray–Curtis community composition, although unequal multivariate dispersion requires cautious interpretation.
- Mock and freshwater creek samples showed relatively low within-group compositional variation.

## Scope and limitations

This is an exploratory downstream analysis of a processed example dataset. It does not reproduce raw-read processing, primer trimming, denoising, chimera removal, or taxonomic assignment.

The dataset contains heterogeneous environments and small, unequal sample-type groups. Sequencing data are compositional, alpha-diversity estimates were calculated from rarefied counts, and dispersion results for groups with two samples are not informative.

## Installation

### R dependencies

Install R and the required packages. From the project root:

```r
source("scripts/install_dependencies.R")
```

TinyTeX is optional and only required for PDF rendering. The automated Snakemake workflow renders HTML and does not require TinyTeX.

### Snakemake

Install Snakemake in an isolated Conda or Mamba environment:

```bash
mamba create -n snakemake -c conda-forge -c bioconda snakemake
conda activate snakemake
```

## Reproduce the workflow

From the repository root:

```bash
snakemake --snakefile workflow/Snakefile --cores 1 --dry-run
snakemake --snakefile workflow/Snakefile --cores 1
```

The generated output files are written to `results/`.

## Render the standalone report

The standalone report is retained as an archived self-contained version:

```text
reports/microbiome_16s_analysis_standalone.Rmd
```

It can be knitted manually in RStudio. The active report, `reports/microbiome_16s_analysis.Rmd`, is rendered automatically by Snakemake.

## Reproducibility note

The current workflow uses the installed R environment on the host system. A future enhancement would add Snakemake rule-specific Conda environment definitions under `workflow/envs/` to pin R and package versions. Snakemake supports isolated rule-specific environments, which is recommended for stronger cross-system reproducibility. [489][490]

## Limitations

Results are exploratory because the dataset contains heterogeneous environments and small, unequal sample-type groups.
